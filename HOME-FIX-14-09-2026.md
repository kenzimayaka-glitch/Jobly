# JOBLY — Correction page d'accueil / parcours pré-ecosystem

Base : JOBLY-AUTH-RESTORED-MORNING-V9

## Corrections appliquées
- Validation e-mail renforcée côté interface avant l'envoi OTP.
- Ajout d'un bouton « Renvoyer le code » sur l'étape OTP afin d'éviter un parcours bloqué.
- Ajout de retours explicites entre les étapes accueil → inscription → OTP → finalisation → connexion/récupération.
- Ajout de `type="button"` sur les contrôles d'action afin d'éviter les soumissions implicites.
- Amélioration des labels/accessibilité des champs OTP et des boutons afficher/masquer le mot de passe.
- Ajout de `aria-live="polite"` pour les messages d'erreur/succès.
- Le sélecteur FR/EN traduit maintenant réellement les libellés du parcours principal, au lieu de ne traduire que le hero.
- Les bénéfices de l'accueil suivent également la langue sélectionnée.
- Les champs e-mail utilisent `type="email"`.
- Texte alternatif de l'illustration amélioré.

## Préservation stricte
- Aucun changement à `lib/auth.ts`.
- Aucun changement aux routes/API d'authentification.
- Aucun changement à `/ecosystem` ou aux pages après `/ecosystem`.
- La logique username + mot de passe, OTP e-mail, Google, récupération de mot de passe et création du profil reste la logique de référence.
